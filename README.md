# 🌐 Web Traffic & User Session Analytics Dashboard

Interaktywny dashboard analityczny stworzony w **Tableau Public**, przeznaczony do kompleksowej analizy ruchu na stronie internetowej, zachowań użytkowników, kanałów pozyskiwania ruchu (Acquisition Channels) oraz demografii i technologii.

### 📊 Kluczowe Obszary Analizy

* **Kanały pozyskiwania (Channels):** Podział ruchu na sesje z `Organic Search`, `Paid Search`, `Direct`, `Social Search` i inne.
* **Przeglądarki i Systemy (Browser & OS / Device):** Analiza ruchu pod kątem urządzeń (`Desktop 58.48%`, `Mobile 39.27%`, `Tablet 2.25%`), przeglądarek (`Chrome`, `Safari`, `Edge`, `Firefox`) oraz systemów operacyjnych.
* **Geografia i Język (Country & Language):** Rozkład ruchu według kontynentów (`Americas`, `Asia`, `Europe`), poszczególnych krajów oraz dominujących języków użytkowników (np. `en-us`).
* **Dynamika sesji w czasie (Dynamic of Session):** Wartości i trendy udziału procentowego poszczególnych kanałów i kontynentów w ujęciu dziennym.
